# Pregunta 2:
**¿Por qué nombre y precio son val pero cantidad es var?**
nombre y precion son val porque sus datos no deben cambiar una vez que esten definidos (inmutables,  la cantidad es var poque sus datos se pueden cambiar (mutables)

**¿Qué pasaría si intentas cambiar el precio después de crear el producto?**
Se mostrara un error de compilacion, ya que una propiedad con val no permite cambios de su valor.
